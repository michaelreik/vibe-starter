```
Vision: <one-line vision>

Queued: <top 3 backlog items, comma-separated>

```

Don't dump the file. Synthesize.

If `PROGRESS.md` is missing or unfilled, recommend the user run `/setup` (if no `.vibe-state.json`) or describe their project so the file can be initialized.
