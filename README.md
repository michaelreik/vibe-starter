# vibe-starter

A "Vibe-Coding Starter Kit": template repository plus CLI wrapper that lets a
less technical person go from idea to live deployed web app in <15 minutes
using a coding agent (Claude Code, Cursor) — complete with GitHub repo,
Supabase database including auth, and Vercel hosting.

**Status:** Design phase. See [`docs/superpowers/specs/2026-04-30-vibe-starter-design.md`](docs/superpowers/specs/2026-04-30-vibe-starter-design.md).
